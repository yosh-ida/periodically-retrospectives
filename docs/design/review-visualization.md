# Review Visualization Design

## Goal

`/themes/:id` で、その反省点に紐づく振り返り履歴の推移を折れ線グラフとして可視化する。

## Data Source

- `reviews` テーブルから `themeId` に一致するレコードを取得する
- グラフ描画には次の項目を使う
  - `reviewedAt`
  - `score`
  - `note`
- 表示順は `reviewedAt` 昇順とする

## Chart Rules

- グラフ種別は折れ線グラフとする
- 横軸の表示間隔は次の 3 種類を持つ
  - `そのまま`
  - `週単位`
  - `月単位`
- 縦軸は 1 から 7 の固定スケール
- `そのまま` では各 `ReflectionReview` を 1 点として表示する
- 隣接する点を線で結び、評価推移を読めるようにする

## Aggregation Rules

- `週単位` では同一週に属する振り返りを集約する
- `月単位` では同一月に属する振り返りを集約する
- 集約値は、その期間に含まれる `score` の平均を計算し、表示用に四捨五入して 1 から 7 の整数に丸める
- 集約点の時刻ラベルは、その週または月を識別できる表記にする
- 集約元データが 1 件だけでも、その期間の代表点として扱う
- どの表示間隔でも元データ自体は保持し、表示用データだけを切り替える

## Note Interaction

- `note` を持つ点は、通常の点と区別できる見た目にする
- `note` を持つ点を選択したときだけ、メモ内容を表示する
- 表示方法はツールチップ、ポップオーバー、またはサイドパネルのいずれでもよい
- `note` を持たない点では、メモ表示 UI を出さない
- `そのまま` では、選択した点に紐づく単一の `note` を表示する
- `週単位` と `月単位` では、対象期間内の `note` を一覧でまとめて表示する
- 集約期間内に `note` が 1 件以上あれば、その集約点を `note` ありとして扱う
- 集約期間内の `note` は `reviewedAt` 昇順または降順のいずれかで統一して表示する

## Empty And Sparse States

- 振り返りが 0 件なら、グラフの代わりに未記録状態を表示する
- 振り返りが 1 件だけでも、その 1 点を表示する
- データ件数が少ない場合でも縦軸スケールは 1 から 7 を維持する

## UI Placement

- 配置先は `/themes/:id` の反省点詳細ページとする
- 課題、原因、ゴールの確認導線を妨げない位置に配置する
- 直近の履歴一覧がある場合は、グラフと履歴が相互補完になるように並べる

## Retrieval And Rendering Notes

- グラフ用データは `themeId` で取得した `reviews` から導出する
- `note` の有無は描画前に判定して、点の見た目に反映する
- 表示間隔の切り替え時は、元の `reviews` から表示用の点列を再計算する
- 集約表示用データは少なくとも次を持つ
  - 期間識別子
  - 表示用スコア
  - 集約対象の review 一覧
  - 期間内 `note` 一覧
- 描画ライブラリは実装時に選定してよいが、折れ線、点選択、補足 UI を実現できることを条件とする
